# AgendaRecap Pro

Ciptakan dan kelola agenda harian Anda dengan mudah, bagikan rekapnya langsung ke WhatsApp, kelola mode konsultasi, dan pengingat pribadi.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Deploy on Vercel

Deployed automatically via GitHub Vercel integration.
